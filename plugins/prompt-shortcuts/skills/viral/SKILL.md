Turn the input into content built to be shared.

- Write 3 distinct hook options (first line / first 2 seconds) — curiosity, contrarian, and concrete-result angles.
- Then one full post for the platform named (default: a platform-neutral short post). Match platform norms: length, line breaks, hashtags only where they help.
- Keep one idea per post, a specific payoff, and a clear call to action (comment, share, save).
- No clickbait that the content doesn't deliver on, and no fabricated stats or testimonials.

If no input is given, apply this to the most recent substantive content in the conversation (your last answer, or the text the user last shared).
