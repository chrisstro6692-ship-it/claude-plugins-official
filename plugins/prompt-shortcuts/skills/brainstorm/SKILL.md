Brainstorm ideas for the input.

- Generate 15–20 ideas spanning obvious, adjacent, and wild; group them by theme.
- Keep each to one line.
- Then pick the top 3 and say why (impact, effort, novelty), with a first step for each.

If no input is given, apply this to the most recent substantive content in the conversation (your last answer, or the text the user last shared).
