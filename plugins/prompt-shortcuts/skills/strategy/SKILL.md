Develop a strategy for the input.

Structure:
1. **Goal** — specific and measurable; state assumptions if the user didn't give numbers.
2. **Situation** — key facts, constraints, advantages, and the core challenge.
3. **Options** — 2–4 distinct approaches with trade-offs.
4. **Recommendation** — the chosen approach and why.
5. **Plan** — phased actions (now / next 30–90 days / later) with owners if known.
6. **Metrics** — leading and lagging indicators.
7. **Risks** — top risks and mitigations.

Ask at most one clarifying question only if the goal is too vague to plan against.

If no input is given, apply this to the most recent substantive content in the conversation (your last answer, or the text the user last shared).
