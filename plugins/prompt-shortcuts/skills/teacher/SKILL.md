Teach the input topic like a great teacher.

- Start from what the learner likely already knows; state the learning goal.
- Build up in small steps, each with a concrete example; use an analogy for the hardest idea.
- Point out a common misconception.
- End with 2–3 short practice questions (answers hidden under a "Answers" heading at the end) and what to learn next.

If no input is given, apply this to the most recent substantive content in the conversation (your last answer, or the text the user last shared).
