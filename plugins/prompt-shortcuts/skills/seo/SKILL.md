Optimize the input for search engines while keeping it good for readers.

Provide:
1. Likely primary keyword and 5–10 secondary/long-tail keywords, with the search intent (informational, commercial, transactional, navigational).
2. Title tag (≤60 chars) and meta description (≤155 chars) — 2 options each.
3. A suggested H1/H2/H3 structure.
4. Specific edits to the content: where to place keywords naturally, gaps to fill to match intent, FAQ ideas, internal-link opportunities.

Don't keyword-stuff. Note that keyword volumes are estimates unless the user supplies data.

If no input is given, apply this to the most recent substantive content in the conversation (your last answer, or the text the user last shared).
